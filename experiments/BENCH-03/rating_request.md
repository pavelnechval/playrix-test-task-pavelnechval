# Rating request for the external model (BENCH-03)

Attach `sheets/compare_large.png` (and optionally `sheets/compare_card_size.png`), then paste the text below the line. Use the same text every round so the ratings stay comparable.

---

The attached sheet shows four rows, one per object. The first image in each row ("real") is an existing card from a casual mobile game. The other images are candidate illustrations, labelled with random codes, made to match that card's art style and composition category.

For each code, give:
1. Style match, from 1 (clearly a different style) to 5 (indistinguishable from the real card's art style).
2. "Players would notice": yes or no. Would a regular player notice a mismatch if this card sat next to the real cards at normal card size?
3. One short sentence explaining the main reason.

Judge rendering (shapes, shading, materials, highlights, outlines), colour (warmth, saturation, background contrast) and composition (camera angle, how large the object is in the frame, how simple the background is). Do not judge which object design is "nicer". Return a table with the columns: code | score | notice | commentary.
