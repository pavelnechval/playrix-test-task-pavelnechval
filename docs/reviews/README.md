## Что не сделано и почему

- **Наборы не разделили на три главных и один дополнительный.** В README сказано, что в брифе три набора, а четвёртый заполняет четвёртый шаблон окна.
- **Маршрут через OpenAI API и таблица оценок без Excel** перенесены в раздел «Что дальше» README.
- **Прогон в macOS** не сделан: под рукой нет Mac.
- **Архив всех промежуточных изображений** не выложен: он большой, отдадим по запросу.
- **Доску не разделили на отдельные фреймы.** Инструменты Miro не переносят готовые элементы в другой фрейм, а пересоздание с удалением старых копий Павел решил не делать: всё осталось в одном фрейме из шаблона.
- **Порядок страниц в PDF** задаётся в Miro вручную: в панели фреймов поставить первыми итог и анализ, при экспорте отметить только свои фреймы. Ссылку на репозиторий дать отдельно, в письме: в PDF ссылки не кликаются.
